# Part A - OLD Godot UI inventory (auth/lobby, loading, discover/events, backpack/emotes, profile)

Paths are relative to `godot/src/` unless noted. "Global" = `src/global.gd` autoload. RN = `rn/src/` (has: `Home.tsx`, `discover/`, `backpack/`, `flow/` (EntryFlow, FtueScreen, flowMachine, auth stub), `world/WorldScreen`, `ds/`). Godot already has an `RnBridge` autoload (`rn_bridge/rn_bridge.gd`, `rn_backpack.gd`, `rn_world.gd`, `rn_avatar_host.tscn`) and `Global.cli.rn_host`, so the RN host drives Godot with JSON commands (`equip`, `unequip`, `set_body_shape`, `set_color`, `play_emote`, `set_emote_slot`, `randomize_avatar`, `set_name`, `enter_world`, `teleport`, `send_chat`, `emote`, `exit_world`, `backpack_open/place/close`) and gets events (`loading` started/finished, `world` entered/exited, `chat`, status).

Global conventions
- Mobile is portrait everywhere except the in-world view (landscape). `Global.set_orientation_portrait()/set_orientation_landscape()`, `Global.is_orientation_portrait()`, signal `Global.orientation_changed(is_portrait)`. In `rn_host` mode `set_orientation_portrait()` just calls `_follow_host_orientation()`. `main.gd` forces portrait at boot unless `rn_host`.
- Teardown guards: `_signing_out`, `_returning_to_discover` swallow stray landscape flips.
- Persisted settings live in `config/config_data.gd` (`Global.get_config()`, `save_to_settings_file()`); keys named per screen below.
- Metrics: every screen calls `Global.metrics.track_screen_viewed(NAME, json)` / `track_click_button(btn, screen, json)`; names listed per screen (RN must keep the taxonomy).
- All user-facing strings are translation keys (`godot/locale/*.csv`, `tr()`); keys named where seen.

- Server-backed features that RN could call directly (signed fetch needed): notifications API, events API, places like/dislike, account deletion, IAP credits, Intercom ticket proxy; social service is gRPC-style via Rust `Global.social_service` (needs bridge or reimplementation).
- All modals route through `Global.modal_manager` (travel, world, external link, teleport, add-email, reward, IAP terms, bug report); toast API `NotificationsManager.show_system_toast`.
- i18n: all strings via translation keys in `godot/locale/*.csv` (en, es, pt_BR); RN needs the same catalogue/keys.

## 10. Key risks for the RN port
1. `RnUiFilter` hides the crosshair + pointer tooltip: scene interaction prompts are invisible in RN today.
2. Scene UI, joypad, joystick and camera-look remain native; RN overlays need pass-through hit testing and must respect `get_interactable_area()`.
3. Orientation/safe-area ownership moved to RN; Godot HUD margin constants (108/32/108/45) no longer apply.
4. Many system flows (ban, disconnect, session ended, update, low-spec, scene timeout) are modals owned by `ModalManager` with no Figma coverage; RN needs events (`modal`/`toast`) or Godot must keep drawing them (RnUiFilter currently hides `UI` children including `Control_Menu`-hosted modals only if they are under `%UI`; ModalManager uses its own CanvasLayers, so they are NOT hidden by the filter and still draw natively).
