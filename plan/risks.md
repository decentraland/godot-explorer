# Risks and guardrails

Each risk names the measurement or check that retires it and the phase item that does it. Fill in
the "Measured" column as results come in.

| # | Risk | What we know | Guardrail | Measured |
|---|---|---|---|---|
| R-1 | Memory and fps on low-end Android | Hermes, V8, LiveKit and Godot in one process. Measured so far: 11–15 fps on the debug template, 14–18 on release, not yet compared with the Godot-exported app from the same commit. | Measure a release build on the Moto Edge 60 Pro and an iPhone before committing the backpack to live 3D (2.9). Budget: no worse than the Godot-exported app on fps, +100 MB RSS at most. Re-checked on the RC in 6.5. If it misses: the host fixes, then Plan B (D-open-16), decided at the 1 Nov checkpoint (D-39); the 4.0 sweep no longer waits for it (D-44). | |
